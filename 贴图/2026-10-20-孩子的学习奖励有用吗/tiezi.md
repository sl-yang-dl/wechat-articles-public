# 微信贴图｜四种奖励，四种失败

> 5 张图（1080×1080），`img/tz-01..05.png`。

---

**标题**

```
四种奖励，四种失败，最后我认了
```

**正文**（约 110 字）

```
这么多年，我给儿子设计过四套奖励。

玩具——他说不要了。
卡片——一学年就不玩了。
球鞋——攒钱太慢，没新鲜感了。
游戏——我妥协了。

他的兴趣一直在变，我一直在追。
我用他喜欢的东西，去换他本不愿做的事。

那三个字"第一种"，是奖励换不来的。
```

## 这篇的钩子为什么是"失败"而不是"方法"

刷到的人多半也试过奖励，也在失败。
"四种奖励四种失败"这句能让人立刻对号入座——**因为它说的不是你多会教，是你也白折腾过**。
最后一张的"那三个字"是全文唯一的亮处，留给金句卡，不要提前说破。
