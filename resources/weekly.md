## 四个问题（按顺序问，别跳）

1. 这周最顺的一件事是什么？（先说好的，气氛才松）
2. 这周最卡的一件事是什么？（学习 or 情绪都行）
3. 爸爸 / 妈妈这周哪句话让你不舒服？（你忍住辩解，只记）
4. 下周咱们各做一件小事，是什么？

## 打印表（直接抄）

| 项目 | 孩子写 | 家长写 |
|---|---|---|
| 这周最顺 |   | （不填，只听） |
| 这周最卡 |   | （不填，只听） |
| 想让我改的一句话 |   |   |
| 下周一件小事 |   |   |

## 两条规矩

- **按时长**：15 分钟内结束，拖长就变说教。
- **不评判**：他说"最卡是数学"，你回"嗯，那咱们看看"，别接"早让你多练"。
