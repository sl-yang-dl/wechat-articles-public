  <h1>错题本三栏模板（可直接打印）</h1>
  <p class="summary">错题本不是把错题抄一遍，而是把"为什么错"和"下次怎么不错"留下来。下面这张表我们用了一学期，A4 打印、每页 3~4 道最顺手。</p>

  <h2>一、三栏怎么填</h2>
  <ul class="topics">
    <li><span class="cat">① 原题</span>剪下来贴，或抄关键条件。别抄整页卷子，只留"错的那一道"。</li>
    <li><span class="cat">② 错在哪</span>选一类：<b>算错 / 看错条件 / 知识点不会 / 思路卡住 / 粗心</b>。只写一类，逼自己定位。</li>
    <li><span class="cat">③ 复盘</span>写"正确思路一句话 + 一道同类题去哪找"。不写长，写"下次见到这类题我先想____"。</li>
  </ul>

  <h2>二、打印模板（直接抄这个结构）</h2>

  <h2>三、用起来的三步</h2>
  <p><b>当天：</b>错的当晚就贴进本子，别攒到周末（攒着就不想动了）。</p>
  <p><b>周末：</b>翻这周错题，把"同类"的归一堆，找它们共同的那个知识点。</p>
  <p><b>考前：</b>只翻错题本，不翻卷子。本子越薄，说明你真会了越多。</p>

  <h2>四、三个常见坑</h2>
  <ul class="topics">
    <li><span class="cat">坑1</span>抄题耗时 → 用剪刀胶棒，剪卷子最快。</li>
    <li><span class="cat">坑2</span>只抄不写"错因" → 没有②那栏，这本子等于白做。</li>
    <li><span class="cat">坑3</span>家长代写 → 让孩子自己填③，你只核对。</li>
  </ul>
